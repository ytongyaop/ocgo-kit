# 知识库

## 步骤
1. 先读 `{{KNOWLEDGE_ROOT}}\AGENTS.md`（库内 schema 是真源），按它的目录与命名规则干活。
2. 定主题：和用户确认要跟的方向，默认取当前学习/求职主线。
3. 搜料：GitHub（trending、`awesome-*`、官方 repo）+ 权威站（官方文档 / arXiv / 机构报告）；候选清单先给用户过目，不擅自定。
4. 原文进 `raw\`：按主题分子目录，一稿一文件；raw 只读，不改不删。
5. 摄入 wiki：新建或更新 `wiki\` 页并写来源指针；与旧页**对账**，标出矛盾或被推翻的旧说法。
6. 跑 lint：孤立页、缺双链、过时说法；FAIL 不得宣称维护完成。
7. 追加日志：`## [YYYY-MM-DD] ingest | 标题`；需要时按 schema 刷新快照记录。

## 产出要求
- 每个 wiki 结论都能追到 raw 里的原始材料（链接或文件名）。
- 对账清单非空：改了哪些旧结论、依据是什么。
- lint 结果贴命令输出（通过/未通过各几条）。

## 边界
- 只动 `{{KNOWLEDGE_ROOT}}`；不碰项目仓库、不改 `.obsidian\`。
- raw 只增不改；wiki 与 schema 一致。
- 硬规则见 `AGENTS.md#门禁`。
