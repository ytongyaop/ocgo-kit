# 流程说明书:项目启动对齐

**触发意图**:用户想开新项目 / 说要做一个东西(如"我想做个…")。

**步骤**(一次只做一步,每步等用户确认):

1. 问清这个项目想做什么(信息不足先问);顺手和用户约一个**简短、唯一、稳定**的代号,登记进索引实体。
2. 带我过**可行性三问**:技术可行 / 经济可行 / 时间可行;任一"不行"就帮用户缩范围或劝退。
3. 整理 `docs/PRD.md` 一页:给谁用 / 解决什么 / 核心功能清单(v1 最小可用)/ 明确不做什么 / 成功标准。
4. 触发架构设计,产出 `docs/架构.md`:**内核** = `domain` 领域规则 + 编排;**外围按需** = `llm` / 界面 / API / `db` / 知识库 / `tools`;依赖单向、外层依赖内层。架构变 → 先更文档再改代码。
5. 建骨架:目录结构 + `docs/进度.md`(全 todo)。可复用模板放 `~/.config/opencode/templates/`。

**门禁**: "不做什么"没写清不开工;可行性任一不行先缩范围。

**关联记忆/文档**:新建项目记忆实体(含代号);`docs/PRD.md`、`docs/架构.md`、`docs/进度.md`。

**命名与关键词约定(便于检索)**:
- **开工先定代号**:和用户约一个**简短、唯一、稳定**的代号(如 `alpha`、`beta`),写进记忆实体名与观测内容,并登记索引实体。
- **观测格式**:`【关键词·YYYY-MM-DD】...`,开头带代号 + 别名 + 场景;项目类记录一律带时间前缀。
- **完结即归档**:明细移入你的记忆存档文件,MCP 只留"一句话摘要 + 指向存档",并在索引实体标"已完结"。
- **索引维护**:新项目加一行、完结改状态、删除时删行;保持索引实体精简(一行一条,不写细节)。

**用中文、步骤化、多讲"为什么";不要跳过门禁。**
