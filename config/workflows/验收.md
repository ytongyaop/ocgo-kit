# 流程说明书:验收

**触发意图**:实现刚做完,用户要验收 / 检查(如"验收""检查一下""行不行")。

**步骤**:

1. **逐条**对照 specs 里的验收标准,打勾 / 标注未过。
2. 带用户跑一遍(默认手动档),看结果、看 diff,多讲"为什么"。
3. 列出没通过的项。

**测试分档**:默认以**手动验证**为主;纯函数建议加**单元测试**;必要时再上**端到端**。按项目复杂度取舍。

**门禁**: 全部通过才准收尾,否则**打回实现**。

**关联**: 当前项目 `specs/NNN-*.md` 的验收标准 + `docs/进度.md`。用中文、步骤化。
