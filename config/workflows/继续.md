# 流程说明书:继续 / 接续中断的工作

**触发意图**:用户回来说"继续""接着做""上次到哪了",或明显在续接某个中断的项目/任务。

**步骤**:

1. **认项目**:确认在说哪个项目(从记忆实体 / `docs/进度.md` / 最近 `specs/` 找线索);**拿不准先问是哪个项目**。
2. **读状态**:读该项目记忆实体 + `docs/进度.md`;需要时读最近一份 `specs/NNN-*.md`(看它停在"规格"还是"计划第几步")。
3. **报进度**:一句话说清"上次到哪、下一步干嘛",**等用户确认**再往下。
4. **按阶段门禁续走**:停在规格 → 继续规格;停在计划第 N 步 → 从第 N 步实现;停在中途 → 对齐后继续。门禁照旧(未确认不写代码)。

**跳出**:若用户其实不是要续接工作(只是闲聊 / 问别的),不套本流程。

**关联**:该项目记忆实体、`docs/进度.md`、相关 `specs/NNN-*.md`。
