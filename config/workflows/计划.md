# 流程说明书:计划

**触发意图**:规格已确认,用户要出计划(如"出计划""怎么做")。

**步骤**:

1. 为当前功能的 spec 文件追加 `## 计划` 段(同一文件),含 6 项:
   拆步 / 改动清单 / 每步验证 / 回退点 / 不碰清单 / 风险未知
2. 以该 spec 的 `## 规格` 段为依据;拆步按功能大小自适应(小功能 2 步 / 大功能 3-5 步,地板 2 步)。
3. 只写 HOW,最多到接口 / 函数签名级别,不写完整实现。
4. 生成后**停下**等用户确认。

**门禁**: **未确认计划不写代码**。

**关联**: 当前项目记忆实体 + 同一 `specs/NNN-*.md`。
