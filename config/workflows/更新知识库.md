# 流程说明书:更新知识库

**触发意图**:用户说"更新知识库 / 找点新资料摄入 / 定期更新",或**每两周**一次的例行。

**频率**:**每两周**(或用户点名时)。

**步骤**(一步一停,重要来源先给用户过目):

1. **定主题**:和用户确认要跟的方向(默认 = 当前学习 / 工作主线,如 Agent 编排、RAG 评估、行业动态)。
2. **搜料**:去 **GitHub**(trending、`awesome-*` 列表、官方 repo)与**权威站**(官方文档 / 机构报告 / arXiv / 权威媒体)搜索。
3. **筛选**:看**权威性 + 时效性**(优先当年);列候选清单给用户过目,不擅自定。
4. **存 raw**:存入 `~/knowledge/raw/`(按主题分子目录, 如 `文章-xxx/`;`raw/` 只增不改)。
5. **摄入 / 更新**:建/更新 `知识 wiki/` 页(`sources/` + `concepts/` + `career/` …),并**对账**——标出与旧页**矛盾**或被**推翻**的旧说法。
6. **lint**:查孤立页 / 缺双链 / 过时说法。
7. **记 log**:在 `知识 wiki/日志 log.md` 追加一条(`## [YYYY-MM-DD] ingest | 标题`)。

**关联**:库内 schema = `~/knowledge/AGENTS.md`;库位置 `~/knowledge`。
